# PasswortGenerator v0.19.0 – Sicherheit, Profile und Oberfläche

**Entwicklungsschritt 19 von 100 bis zur ersten Vollversion. Alle besprochenen Verbesserungen gemeinsam in einer Veröffentlichung.**

## Deutsch

- **Navigation:** „Design“ heißt jetzt durchgehend **„Einstellungen“**. Die Reihenfolge oben lautet **Passwort → Update → Einstellungen → Info**.
- **Zwischenablage:** Kopierte Passwörter werden auf Wunsch nach **30, 60 oder 120 Sekunden** gelöscht. Standard sind 60 Sekunden. Nur das unveränderte, von der App kopierte Passwort wird entfernt; zwischenzeitlich kopierte andere Inhalte bleiben erhalten.
- **Passwort-Profile:** **Standard**, **Sehr sicher**, **Einfach** und **Eigenes Profil**. Ein eigenes Profil lässt sich speichern und wieder laden. Gespeichert werden ausschließlich Länge und Zeichenauswahl, niemals generierte Passwörter.
- **Glass-Design:** Dezente Glanzkanten, besser erkennbare Hover- und Fokuszustände und kompaktere Einstellungen, weiterhin ohne aufwendige Unschärfeeffekte.
- **Update-Bereich:** Installierte und verfügbare Version im direkten Vergleich; bis zu zwei Änderungen der neuen Version als Vorschau in der gewählten Programmsprache. Die bestehende **Changelog**-Kachel bleibt erhalten.
- **Deutsch/Englisch:** Alle neuen Einstellungen und Update-Hinweise folgen der bereits vorhandenen zentralen Spracheinstellung.
- **Unverändert:** SHA-256-geprüfte Updates nur nach Bestätigung, zwei Stunden Updateintervall, lokale Passwortgenerierung, Fenstergröße und -position, grafische Hilfe, Linux-AppImage-Sicherung.

## English

- **Navigation:** “Design” now consistently reads **“Settings”**. Top order: **Password → Update → Settings → Info**.
- **Clipboard:** Optionally clear app-copied passwords after **30, 60 or 120 seconds** (60 seconds by default). Only an unchanged copied password is removed; newer clipboard content is preserved.
- **Password profiles:** **Standard**, **Very secure**, **Simple** and **My profile**. Save and restore personal password settings without saving generated passwords.
- **Glass design:** Refined highlights and more visible hover and keyboard-focus styles without expensive blur effects.
- **Updates:** Compare installed and available versions, plus a two-item preview of release changes in the selected language; the existing **Changelog** card stays.
- **One app language:** New settings and status messages use the same German/English preference.
- **Retained:** Checksum-verified, consent-based updates, two-hour checking interval, local generation, saved window geometry, illustrated help and previous AppImage backups.
