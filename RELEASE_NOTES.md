# PasswortGenerator v0.21.0 – Ocean Glass als Standarddesign

## Deutsch

- **Echtes neues Standarddesign:** Die zuvor als Konzeptbild gezeigte moderne blau-cyanfarbene Oberfläche ist jetzt in die **funktionierende Qt-App einprogrammiert**. Kein eingefügtes Mockup und kein bloßes README-Bild.
- **Ocean Glass:** Dunkle navyblaue Kacheln mit feinen cyanfarbenen Lichtkanten, glänzende Navigationsreiter, neue Eingabefelder, verbesserte Hover-Zustände, ein blau-türkiser Generieren-Button und eine grüne Sicherheitsanzeige.
- **Neuer Hintergrund:** Weiche blaue, fließende Bänder. Das Motiv wird **lokal einmal mit Qt gezeichnet**, bleibt offline verfügbar und verursacht keine dauernden Neuzeichnungen beim Vergrößern des Fensters.
- **Passwortseite:** Ein eigener Titelbereich neben dem Passwort/Passphrase-Umschalter, bei schmalen Fenstern automatisch kompakt.
- **Als Standard:** Frische Installationen starten automatisch mit Ocean Glass. Bei älteren Installationen wird das unveränderte bisherige Neon-Standarddesign einmalig auf Ocean Glass umgestellt. Selbst gewählte andere Designs, eigene Farben und Hintergrundbilder bleiben erhalten.
- **Weiterhin verfügbar:** Alle bisherigen Farbschemas, Deutsch/Englisch, sichere Passwort- und Passphrasenerzeugung, Profile, Zwischenablageschutz, Changelog und geprüfte Updates.
- Linux-/Windows-Oberflächentests einschließlich verschiedener Fenstergrößen; die README zeigt eine echte Linux-Aufnahme der aktualisierten Anwendung.

## English

- **Real new default UI:** The blue/cyan style previously shown as a concept image is now implemented in the **working Qt application** – not a mockup or just a README picture.
- **Ocean Glass:** Navy translucent cards with cyan highlight edges, glowing navigation, styled inputs and hover effects, a blue-to-cyan Generate button, and a green strength indicator.
- **Built-in backdrop:** Flowing blue ribbons are drawn **once locally by Qt**, available offline with no resize-time repaint loop.
- **Password page:** A dedicated title area next to the Password/Passphrase mode selector, collapsing at narrow widths.
- **New default:** Fresh installs use Ocean Glass automatically. Existing installs on the unchanged old Neon default migrate once; explicitly selected other themes, custom colors, and wallpapers are kept.
- **Retained:** All previous schemes, both UI languages, strong password generation and passphrases, profiles, clipboard safety, release notes, and verified updates.
- Linux/Windows visual regression tests including different window widths, plus a genuine Linux screenshot in the README.
